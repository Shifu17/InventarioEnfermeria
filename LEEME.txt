INVENTARIO DE ENFERMERÍA · FAENUS UAdeC
=======================================

INSTALAR (lo más fácil)
- Descarga InventarioEnfermeria.exe de la última versión:
  https://github.com/Shifu17/InventarioEnfermeria/releases/latest
- Guárdalo en una carpeta tuya (por ejemplo Documentos o el Escritorio) y ábrelo.
- No necesita Python ni instalación.

INVENTARIO EN LÍNEA
- El inventario y sus fotos viven en un repositorio privado de GitHub
  (Shifu17/InventarioEnfermeria-datos). Cada computadora lo descarga sola al abrir el
  programa; no hay que configurar nada.
- Los cambios se suben y bajan automáticamente cada pocos segundos. El estado aparece
  abajo en la barra lateral; "Sincronizar ahora" lo fuerza.
- Sin internet se sigue trabajando: los cambios se guardan en la computadora y se suben
  al volver la conexión. Si dos computadoras cambian el mismo equipo, gana el cambio
  más reciente.
- Copia local: %LOCALAPPDATA%\InventarioEnfermeria (inventario.db y fotos\).

ACTUALIZACIONES
- Al abrir, el programa revisa en GitHub si hay una versión nueva y pregunta si quieres
  actualizar. También puedes usar "Buscar actualizaciones" (abajo en la barra lateral).
- Al actualizar se reemplaza el .exe y se abre de nuevo. Tus datos no se tocan.
  (Se guarda una copia del .exe anterior como InventarioEnfermeria.exe.anterior.)

USO
- Buscar: nombre, # folio, No. de inventario, marca, modelo o serie (Ctrl+F).
  Varios folios: 1,2,3   ·   Rango: 1-10. Enter abre el equipo si hay un solo resultado.
- Áreas: barra lateral izquierda. "Nueva área" agrega una; "Renombrar", doble clic o
  clic derecho cambian el nombre (si ya existe otra con ese nombre se pueden unir).
- Equipos dados de baja: al poner el estado "Dado de baja" el equipo pasa solo al área
  "EQUIPOS DADOS DE BAJA". Si cambias el estado, regresa a su área original.
- Costo: campo "Costo (MXN)" en la ficha del equipo. El total aparece arriba del listado
  y en el Excel exportado.
- Agregar equipo: botón azul "Agregar equipo" (Ctrl+N). Editar: clic sobre una tarjeta o fila.
- Foto: "Cambiar foto" o arrastra la imagen al recuadro. Clic sobre la foto para verla en grande.
- Exportar a Excel: una hoja por área, con fotos, costos y total por área.
- Modo oscuro: botón "Modo oscuro" / "Modo claro" en la barra lateral (se recuerda en cada PC).

DATOS Y RESPALDO
- En la carpeta de datos están inventario.db (base de datos) y fotos\.
  "Abrir carpeta de datos" la muestra. Para respaldar, copia esa carpeta completa.
- Los errores inesperados se anotan en %LOCALAPPDATA%\InventarioEnfermeria\errores.log.

PARA DESARROLLADORES
- Ejecutar desde el código: "Iniciar Inventario.bat" (necesita Python 3.10+).
- Crear el .exe local: "Crear EXE.bat" -> dist\InventarioEnfermeria.exe
  Necesita el código de acceso a los datos en token_datos.txt (no se sube a git).
- Publicar una versión nueva (los programas instalados la recibirán solos):
  1. Cambia VERSION en app\version.py (por ejemplo 1.2.0) y describe los cambios
     en NOTAS_VERSION.md.
  2. git commit -am "Versión 1.2.0" && git tag v1.2.0 && git push --follow-tags
  3. GitHub Actions prueba, compila y publica el .exe en Releases automáticamente.
- Pruebas: .venv\Scripts\python -m pytest
- herramientas\migrar_excel.py vuelve a importar el Excel original y REEMPLAZA la base actual.
